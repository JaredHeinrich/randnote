# rn - randnote /ʁantnoʊt/

[![CICD](https://github.com/JaredHeinrich/randnote/actions/workflows/ci.yml/badge.svg)](https://github.com/JaredHeinrich/randnote/actions/workflows/ci.yml)
[![Version info](https://img.shields.io/crates/v/randnote.svg)](https://crates.io/crates/randnote)

`rn` is a tool that helps with managing plaintext note files.

The overall goal is to allow managing multiple plaintext note files all in one
place and make them available from everywhere in the terminal.

[How to use](#how-to-use) • [Installation](#installation) • [Config](#config)

## How to use
When any command is run, `rn` will try to create a directory `$HOME/.rn`.
Thats where the notes will be stored. To simplify the completion scripts
the path of this directory is currently not customizable.

### Subcommand overview

Show help text for an overview of all subcommands:
```
rn
rn --help
```

Create a new note:
```
rn new <NAME>
```

Open an existing note in the configured editor (default = nvim):
```
rn open <NAME>
```

Delete a note:
```
rn rm <NAME>
rn remove <NAME>
```

List all existing notes:
```
rn ls
rn list
```

Generate shell completion scripts (for further details see [Completions](#completions)):
```
rn completions --shell <SHELL>
```

## Installation
`rn` currently only sopports `linux` and `macos`. You might be able to install it
on other operating systems, but it might not work as intended.

### Cargo
To install `rn` with Rust's package manager [cargo](https://github.com/rust-lang/cargo) run:

```
cargo install randnote
```

### From local source
Or install it from local source:
```
git clone https://github.com/JaredHeinrich/randnote.git
cd randnote
cargo install --path .
```

### Completions
Completions are currently only available for `zsh`. But it's planned to also
support other popular shells like `bash`, `fish` in the future.

Use the `completions` command to generate the completion script.

#### Zsh
Generate the completion script:
```
rn completions --shell zsh > _rn
```
And move it to a directory in your `fpath`.

## Config
`rn` can be configured using a config file `rn.toml`. On linux and macos this
should be located at `$HOME/.config/rn/rn.toml`.

The default config can be generated by:
```
rn config generate
```
Which also gives you the path to the config file.
